What went wrong

C1 is OnPush and assigns data inside an HTTP subscribe. When the response arrives, Zone.js triggers change detection, but Zone.js never marks components dirty. Nothing marked C1, so it is skipped and keeps showing "loading...". The Eager C2 is checked on every tick, so it updates. Clicking C1 again reveals the previous response, because the click marks C1 dirty. 

{{ brokenCode }}

The fix

After assigning the response, C1 calls ChangeDetectorRef.markForCheck(). This marks C1 and its ancestors dirty, so the check triggered by Zone.js refreshes it. Using the async pipe would do the same for you.
