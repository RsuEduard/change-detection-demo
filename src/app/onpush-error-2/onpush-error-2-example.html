What went wrong

P1 mutates prop2.name. The object passed to C2 is still the same reference, so Angular sees no input change and does not mark C2 dirty. C2 is skipped and keeps the old name, even though P1 shows the new one. C1 updates because its string input changed.

The fix

P1 creates a new object instead of mutating it: prop2 = {{ '{' }} ...prop2, name {{ '}' }}. A new reference counts as an input change, which marks C2 dirty and refreshes it.
