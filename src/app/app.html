Change detection demo

Orange box = OnPush component Blue box = Eager component

Change detection runs counts how often Angular checked that component (the template calls getCount(), which increments a counter on every check).

@for (tab of tabs; track tab.index) { }
@switch (activeTab()) { @case (1) {

An Eager root with two branches: an OnPush branch and an Eager branch. Each branch has an Eager leaf. Every component except the root has a button that does nothing.

Try: click the buttons in each branch and watch which counters go up.

} @case (2) {

P1 (Eager) has two children that load a user over HTTP (with a 1 second delay). C1 is OnPush, C2 is Eager. Both use the same code.

Try: click Load via HTTP in both children and compare their data and counters after the response arrives.

} @case (3) {

P1, C1 and C2 use OnPush change detection. P1 passes prop1 (a string) to C1 and prop2 (an object with a name) to C2 and C3. C3 is otherwise identical to C2, but uses Eager change detection.

Try: click Update prop1 and prop2.name and compare what P1, C1, C2 and C3 show. Then click Local click inside C2.

} @case (4) {

P1, C1 and C2 use OnPush change detection. P1 passes prop1 to C1. C2 and C3 have no inputs: P1, C2 and C3 all inject a shared NameService that holds a name string. P1's button updates prop1 and calls nameService.update(). C3 is otherwise identical to C2, but uses Eager change detection.

Try: click the update button and compare what P1, C2 and C3 show. Then click Local click inside C2.

} @case (5) {

P1, C1 and C2 all use OnPush change detection and are nested P1 → C1 → C2. A shared NameSignalStore holds a name string signal. P1's button calls nameStore.update(), which sets a new value. Only C2 reads the signal in its template. C1 has no inputs and does not read the signal.

Try: click Update name signal and compare the counters. P1 is checked because the click happened in its template. C1 is skipped. C2 is checked because it reads the signal, and it shows the new name.

} @case (0) {

A single Eager component. None of the buttons change any data: one does nothing, one starts a setTimeout, and one starts three setTimeouts.

Try: click each button and count how many checks it causes.

} }
